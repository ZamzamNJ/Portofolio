## 🚀 Cara Menjalankan Website

Anda memiliki **2 cara mudah** untuk melihat dan menjalankan website ini:

### Cara 1: Langsung Dibuka di Browser (Tanpa Perlu Terminal/Install)
1. Buka folder `c:\Users\userr\Downloads\Portofolio\` di File Explorer Windows Anda.
2. Klik ganda (double click) file **`index.html`**.
3. Website akan langsung terbuka dan berjalan sempurna di Google Chrome, Microsoft Edge, atau browser favorit Anda!

### Cara 2: Menjalankan dengan Node.js & Vite (Development Server)
Jika di komputer Anda telah terpasang Node.js:
1. Buka PowerShell atau Command Prompt di folder ini:
   ```bash
   cd c:\Users\userr\Downloads\Portofolio
   ```
2. Pasang dependensi:
   ```bash
   npm install
   ```
3. Jalankan server lokal:
   ```bash
   npm run dev
   ```
4. Buka tautan lokal yang tampil di terminal (misalnya `http://localhost:5173`).
